# ☕ Hotcoffee: Landing Page de Receitas para Devs

Uma Landing Page responsiva, moderna e temática voltada para a comunidade de desenvolvedores. O projeto funciona como um catálogo interativo e mural de receitas de cafés e bebidas quentes compartilhadas por profissionais de tecnologia ao redor do mundo.

---

## 🏗️ Arquitetura e Semântica Web

A estrutura do projeto foi planejada utilizando as melhores práticas do **HTML5 Semântico**, garantindo acessibilidade, melhor indexação em motores de busca (SEO) e um código limpo e de fácil manutenção (*Clean Code*):

* **Componentes Semânticos:** Uso correto de tags estruturais como `<header>` (cabeçalhos globais e locais), `<nav>` (menus de navegação), `<main>` (conteúdo principal), `<section>` (divisões temáticas) e `<footer>` (rodapé informativo).
* **SEO & Metadados:** Inclusão estratégica de meta tags de descrição (`description`) personalizadas, preparando a página para compartilhamento e buscas orgânicas.
* **Componentização de Cards:** Estruturação modular de blocos informativos (`card-da-receita`) reaproveitáveis, simulando componentes dinâmicos com dados de autores integrados diretamente via avatares de APIs do GitHub.
